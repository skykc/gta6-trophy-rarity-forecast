A refresh-aware forecaster for GTA VI trophy earn rates on Exophase: it tracks earners and players as separate counts in log-time, so dilution (new players start with zero trophies) falls out of the ratio automatically, and it carries a launch-night refresh prior for histories that show only one snapshot.
## Run it
```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
